# Plataforma E-commerce
API escalable para plataforma de E-commerce utilizando arquitectura de microservicios y Docker. La plataforma contempla varios aspectos de una tienda en línea, como la gestión del catálogo de productos, la autenticación de usuarios, el carrito de compras, el procesamiento de pagos y la gestión de pedidos.
## Stack tecnológico
- Node.js (Express)
- Docker y Docker Compose
- Traefik
- PostgreSQL
